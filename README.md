# 大盘脉搏（基金对比复刻版）

一个离线可运行的基金行情对比页面，复刻自 cn-marketdata.com 的 **#funds 基金页**。
页面样式、交互与数据格式与原站保持一致，但**数据全部来自腾讯公开行情接口**，与原站无关。

---

## ✨ 功能一览

- **ETF 多选比较图**：A股行业（25只）/ 港股（6只）/ 海外（8只）三大分类
  - 支持多选 / 全选 / 全取消，图表同时绘制多条曲线
  - 周期切换：5日 / 20日 / 60日 / 120日 / 250日 / 750日
  - 坐标模式：归一化（起点=100） / 实际值（单选时可用）
  - 鼠标悬停查看数值、横向拖拽平移时间窗口、图例点击显隐曲线
- **基金强弱表**：各分类 1日 / 5日 / 20日涨跌幅排行
- **可交易 ETF 代理**：宽基 5 只 + 行业 12 只，支持 1/5/20 日周期切换
- **亮色 / 暗色主题切换**

## 🚀 使用方法

### 前提条件（仅首次）
1. 安装 **Python 3**（≥3.8）：https://www.python.org/downloads/
   安装时务必勾选 **"Add Python to PATH"**。
2. 本机需要能访问互联网（数据更新时需要，查看页面时不需要）。

### 方式一：双击启动（推荐）
双击 `start.bat`，会自动：
1. 检查 Python 是否安装
2. 在本地启动服务器
3. 自动打开浏览器进入页面（http://127.0.0.1:8765/#funds）

> 关闭弹出的黑色命令行窗口即停止服务。

### 方式二：命令行手动启动
```bash
cd 复刻网站
python -m http.server 8765 --bind 127.0.0.1
```
然后浏览器打开：http://127.0.0.1:8765/#funds

## 🔄 更新行情数据

页面默认使用随包附带的 `data/latest.json`（已含最近数据，可直接查看）。
如需获取最新行情：

- 双击 `update_data.bat`，或
- 命令行执行：`python fetch_data.py`

脚本会从腾讯公开接口抓取 39 只 ETF 的历史 K 线与实时快照，生成新的 `data/latest.json`（约 1-3 分钟）。
更新完成后**刷新浏览器页面**即可看到最新数据。

仓库中的 GitHub Actions 会在每个工作日北京时间 08:00 自动运行同一脚本并提交最新快照，也可在 Actions 页面手动触发。

## ⚠️ 常见问题

| 问题 | 解决方法 |
|---|---|
| 双击 start.bat 提示"未检测到 Python" | 安装 Python 3 并勾选 Add to PATH 后重试 |
| 提示"端口 8765 已被占用" | 说明已有一个实例在运行，直接访问 http://127.0.0.1:8765/#funds |
| 页面打开但图表空白 / 数据不显示 | 确认 `data/latest.json` 存在；或重新运行 update_data.bat |
| 数据是旧日期 | 运行 update_data.bat 刷新（需联网） |
| 浏览器页面白屏 | 关闭所有本页窗口，重新双击 start.bat |
